Trinity Request Translation Test Console

A chained translation test across three roles. SEM frames the ask (impact + marketplace + objective) → Brand EPM assigns request type & categories (L1/L2/L3) → Core Team maps execution team, solution path & requirements. Each stage is scored against the Top-20 answer key; you update the model as you test.
